# FOLDER ASSET RESMI - PUSKESMAS KEPULAUAN SERIBU SELATAN

Folder ini digunakan untuk mengumpulkan seluruh berkas media visual, gambar, dan aset grafis resmi website Puskesmas Kepulauan Seribu Selatan.

---

## 📁 Struktur Subfolder

1. **`gambar/`**  
   - Foto gedung puskesmas induk Pulau Tidung (gedung baru 2 lantai).  
   - Foto Puskesmas Pembantu (Pustu Pulau Untung Jawa, Pustu Pulau Pari, Pustu Pulau Lancang).  
   - Foto Pos Kesehatan (Pulau Payung) dan fasilitas rawat inap, IGD, laboratorium.  
   - Foto Dermaga Kapal Ambulans Medis 24 Jam.

2. **`foto-kegiatan/`**  
   - Dokumentasi Posyandu Siklus Hidup ILP (Ibu Hamil, Balita, Remaja, Usia Dewasa, Lansia).  
   - Kegiatan penjangkauan kesehatan keliling (Home Care Bahari).  
   - Penyuluhan kesehatan masyarakat, intervensi stunting, dan PSN (Pemberantasan Sarang Nyamuk).  
   - Pelatihan tenaga kesehatan dan simulasi tanggap darurat maritim.

3. **`nakes/`**  
   - Foto profil resmi Kepala Puskesmas Kepulauan Seribu Selatan.  
   - Pas foto formal jas/seragam tenaga dokter umum, dokter gigi, perawat, bidan, apoteker, nutrisionis, sanitarian, dan staf penunjang.  
   - Ukuran ideal: Aspek rasio 1:1 atau 3:4, resolusi minimal 400x400 piksel.

4. **`slider/`**  
   - Banner tayangan beranda utama (Hero Slider).  
   - Format: JPG / WebP / PNG, resolusi minimal 1920x1080 piksel (Landscape 16:9).

5. **`icons/`**  
   - Lambang Pemprov DKI Jakarta, Dinas Kesehatan, Kemenkes, dan logo puskesmas PRIMA.

---

## 💡 Panduan Penggunaan di Hostinger
- Di web server Hostinger, folder ini dapat diakses langsung secara publik melalui URL `https://domain-anda.com/assets/...` atau `https://domain-anda.com/asset/...`
- Format yang disarankan: `.webp`, `.png`, `.jpg`, `.svg`.
